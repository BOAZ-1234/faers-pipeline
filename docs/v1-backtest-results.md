# v1 백테스트 결과 — ic025×log(a) 랭킹 (ic025 단독 대비 개선)

IC025 단독(초기 v1)을 **ic025 × log(a)**(불균형 × 증거량)로 재정렬하면 전 구간 개선된다.
같은 게이트 후보·같은 정답지, **랭킹 점수만 교체**(새 데이터 無). 수치만 정리.

> 전기간 합산본 기준(PIT 아님). 클래스 수준 정답지(NSAIDs 등) 제외, 복합제는 성분세트로 포함.

|---|---|
| 신호표 (성분,반응) 쌍 | 3,805,363 |

## 재정렬 기준 비교 (등수 중앙% / R@100k)

| 정렬 | 중앙% | R@100k |
|---|---:|---:|
| **ic025×log(a)** | **28.3%** | **29.7%** |
| a (신고수) | 20.3% | 32.9% |
| ic025 단독 | 38.8% | 21.2% |
| ror | 58.9% | 8.1% |
| prr | 58.8% | 8.1% |

- a 단독이 수치는 더 높으나 "유명약=신고많음" 편향 → 불균형 의미 보존하는 ic025×log(a) 채택.
- ror/prr은 소표본 축소 없어 ic025보다 나쁨.

## 선행연구 참고 (느슨한 참고 — 직접비교 아님)

| | 지표 | 값 |
|---|---|---|
| vigiRank (UMC) | precision (VigiBase+전문가검토) | IC025단독 1.2% → 피처 3.1% (≈2.6배) |
| 우리 | Recall/Lift (공개 FAERS+고정 정답지) | Lift@20k 2.6x |

> 지표(precision vs recall/lift)·데이터(VigiBase vs FAERS)·분모가 달라 head-to-head 불가.
> "피처로 ≈2.6배"만 느슨한 참고. 우린 recall을 투명하게 측정(vigiRank은 recall 미측정).
